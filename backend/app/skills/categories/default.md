# 通用选购方法论

以下方法论作为选购辅助参考，非强制规则：

## 核心维度

1. **价格**：券后价 vs 历史价分位，判断入手时机
2. **口碑**：品牌信誉 + 店铺评分 + 用户口碑聚合
3. **销量**：月销反映市场验证程度
4. **券力度**：优惠券折扣率，高折扣高性价比
5. **品牌**：旗舰店/品牌店 > 普通店铺

## 选购原则

- 预算优先：明确上限，先过滤再排序
- 品质底线：DSR 三项评分均 > 4.6 的店铺才考虑
- 好价时机：历史分位 60% 以下（当前价低于历史 40% 的时期）算好价
- 券有效性：检查券领取量和剩余量，领完了的券无意义
