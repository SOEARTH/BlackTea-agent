# 户外露营类选购方法论

适用品类：帐篷、睡袋、炉具、背包、登山装备

## 品类核心维度

- **防水**：帐篷外账防水系数 > 2000mm，睡袋外层 DWR 拒水
- **重量**：背包 < 1.5kg（55L），帐篷 < 2.5kg（双人），单人帐篷 < 1.5kg
- **温标**（睡袋）：舒适温标低于预期最低气温 5°C，极限温标仅参考
- **收纳体积**：折叠后体积越小越便携
- **材质**：航空铝合金（炉具/杖）、尼龙 66（帐篷面料）、羽绒 vs 棉（睡袋）

## 硬约束示例

- "双人" → 帐篷容量 >= 2 人
- "零下10度" → 睡袋舒适温标 <= -10°C
- "铝合金" → 炉具/登山杖材质为航空铝
- "1kg以内" → 商品重量过滤

## 组合采购说明

露营场景常为组合采购（帐篷 + 睡袋 + 炉具 + 背包），
触发背包 DP 优化，按预算约束最大化总得分。

## 推荐工具

- search_goods（搜索 + 价格过滤 + 品类关键词）
- get_price_trend（帐篷/睡袋有季节性价格波动）

## 选购建议

- 新手入门：优先品牌入门款 + 高 DSR 店铺
- 轻量化徒步：重序列克级 -> 克重维度权重最高
- 高海拔探险：温标 + 防风为硬约束，价格可放宽
