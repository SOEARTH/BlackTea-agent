# 音频类选购方法论

适用品类：耳机、音箱、麦克风

## 品类核心维度（在通用 5 维基础上）

- **音质**：频响范围、降噪能力（主动降噪 ANC / 被动隔离）、底噪水平
- **续航**（无线耳机）：单次续航 > 6h 为合格，> 20h 为优秀；充电盒总续航 > 24h
- **佩戴舒适度**：重量 < 250g（头戴）/ < 5g（单耳 TWS），长时间佩戴不压头
- **连接**：蓝牙 5.2+（低延迟），多点连接（跨设备切换）
- **防水**：运动场景需要 IPX4+，游泳需 IPX8

## 硬约束示例

- "续航>20h" → 过滤单次续航 < 20h 的无线耳机
- "降噪" → 必须有 ANC 标识
- "IPX5防水" → 运动场景防水等级

## 推荐工具

- search_goods（搜索 + 价格过滤）
- get_price_trend（历史价格趋势判断入手时机）

## 选购建议

- 通勤降噪：优先 ANC + 舒适度 + 单次续航
- 运动场景：优先防水（IPX4+）+ 骨传导/开放式
- 家用 HiFi：优先有线 + 音质 + 品牌信誉
